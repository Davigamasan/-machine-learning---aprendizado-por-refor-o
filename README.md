## Como rodar localmente
A página é estática, sem servidor. Basta abrir `index.html` no navegador, ou rodar:
```
python -m http.server 8000
```
e acessar http://localhost:8000.

Para o notebook: abra no Google Colab ou rode localmente com `pip install gymnasium numpy matplotlib`.
Testado com Python 3.12, gymnasium 1.3.0, numpy 2.4.4 e matplotlib 3.10.8.
